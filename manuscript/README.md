# Manuscript material in this software distribution

[`visual_benchmark_ja.tex`](visual_benchmark_ja.tex) is the unchanged Japanese working-manuscript insertion describing the visual luminosity experiment. It is preserved as an editorial and provenance record, not as the required software manual. The scientific article is intended for *Astronomy and Computing* and will be translated into English after its content has been fixed. This documentation edition does not claim to translate that complete article.

For the experiment in English, read the [repository README](../README.md), [results](../docs/RESULTS.md), [figure guide](../docs/FIGURES.md), and [reproducibility guide](../docs/REPRODUCIBILITY.md). The older reference experiments have separate [English theory and result notes](../docs/reference/README.md). Those paths do not require reading Japanese.

The manuscript and the Japanese `.tex` work-note fragments in archived stages are not relicensed by the software-licensing step. The existing [licence-scope notice](../docs/LICENSE_SCOPE.md) remains in force. Source file paths, mathematical notation, scientific results, and original fragments were not altered in this documentation revision.
