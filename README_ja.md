# 二バンド光度分布のD補完推定と可視化ベンチマーク

新規リポジトリ名`bivsurv-luminosity`とBSD 3-Clauseライセンスを確定した公開準備版です. この準備版を作成した時点ではGitHubへのアップロードは行っていません. 最新の方法に基づく追加のGaussian光度実験と, 第22–25段階の既存実装・入力・保存証拠を含みます. 旧版で撤回した積分積・重み付けの実装を新法として再公開するものではありません.

## 実行

Python 3.10以上で, このフォルダを作業場所として実行します.

```bash
python -m pip install -e ".[test]"
python scripts/check_release.py
python -m pytest -q
```

上の手順は保存結果を上書きせず, 配布ファイルと単体テストを確認します. 全実験を再実行する場合は, 別の出力先を指定します.

```bash
python scripts/run_benchmark.py --output outputs/rerun
python scripts/verify_visual.py --output outputs/rerun
python scripts/make_figures.py --output outputs/rerun
```

標準設定の実出力は `outputs/visual/` に同梱しています. `quickstart.ipynb` でも手順を追えます. 新規の独立母標本は120個, 総親天体数840000です. 同じ標本を浅い・深い二設計で対比較し, 240設計評価・480EM適合を行います. 別に12個の初期分布感度対照を実行できます.

## 何を図にしたか

本法が直接推定するのは確率分布です. 絶対数密度の規格化はこの実験へ追加していません. 主図では, 最深の限界で少なくとも一方を検出できる領域Uに条件付けたQを使い, 真のQと比較します. ヒートマップはセル確率をdex単位の面積で割ったビン平均密度です. 最深観測でも二つの光度が判定できない部分はハッチとマスクで示します. そこを初期配分や平滑化で埋めて「回復」と呼びません. 数値モデルは非有界セルも含めて全実数平面を保持しています.

誤差は, 記録法則の全変動, 判定できるビンのL1誤差, 固定13×13評価格子でのQの両高光度確率のRMSEを保存しています. 元の親分布Pの参考誤差も別列にあり, 不可視初期質量への依存を隠していません. 周辺図は両成分が共通の評価領域に入る条件付き分布です. 同尤度の親分布族の図は信頼帯ではありません. 反復実験の帯は経験10–90%分位であり, 95%信頼区間ではありません.

## 比較手法

D補完を使う新法と, D補完と選択分母を省いた対照, B/Cを捨てた単純Aヒストグラムを比べます. 後二者は効果を切り分ける対照であり, Lynden–Bell法や正しいA限定切断推定量との比較ではありません. Gaussian母分布の平均とスケールは旧図に合わせましたが, 今回は限界を三つの宣言層にした新実験です. 旧数値結果の再現と呼びません.

## 計算保証の区別

新しい高速実装は, 限界が記録境界と一致する場合に特化した指数配列版です. 旧実装の正確な有理数更新および単点境界の観測写像と照合しています. 一致しない限界を黙って丸めず入力エラーとします. 任意の区間・限界を扱う元の幾何実装は `reference_experiments/` に保存しています.

新しい240候補については尤度履歴・全列スコア・正規化・不可視質量保存・尾部所属を数値検査していますが, 大域近最適性の証明は付与していません. 第25段階の別の13候補に対する既存証拠は今回再検証しました. この二つを混同しないでください. 主EMは尾部制約を自動的に強制する実装ではなく, 本実験では全候補が1/2上界を満たしたことを事後診断しています. 他の入力で不適合なら, 元の制約付きM-stepを使う必要があります.
