# 新しい二変量光度分布の可視化実験

## 実施範囲

Gaussian対数光度の平均 (10.5, 10.2), 標準偏差 (0.55, 0.65), 相関 0.55 と 0.90. 親標本数1000, 4000, 16000, 各20反復を新しく生成した. 独立母標本120個, 総親天体840000. 同じ潜在値・観測層・学習所属を浅い設計と深い設計へ使用し, 240設計評価を行った. D補完とDなしの480適合, 未補正Aヒストグラム240個, 初期分布の追加12適合を計算した.

## 主な結果

`summary.csv` は各反復で誤差を計算した後の平均と標本標準偏差を収録する. D補完の可視規格化積分確率RMSEは, 親1000天体の約0.0086–0.0111から, 親16000天体の約0.0024–0.0030へ減少した. Dなし・単純Aは意図的な機構欠落の対照であり, 正しく構成した歴史的推定量との比較ではない.

主密度図は Q_U=P(.|U) のビン平均密度である. 同時に二つの光度を判定できない領域はマスクし, 外挿で埋めない. 不可視質量は初期条件のまま残り, 全親分布の推定とは区別する. 反復図の帯は経験10–90パーセンタイルであり信頼帯ではない. 同尤度の三候補を描いた曲線も信頼帯ではない.

## 検査

11単体テストに合格. 以前の有理数更新との比較と境界の観測写像を含む. 全240公開入力を潜在配列から再構成し, 全初期更新を密行列と比較した. 別出力先で全新実験を再実行し, 240入力JSONと1808配列の一致, 評価表の実行時間以外の一致を確認した. `verification.json` に保存した. 全新候補は数値スコア条件を満たしたが, 新しい1156質量の候補について大域最適性の証明は計算していない.

以前の第25段階の13候補の独立検証器も再実行した. これは別の小規模モデルの保存証拠であり, 新しい高解像度の図に大域保証を付与するものではない. 第22–25段階の元実装を `reference_experiments/` に保持したが, 旧段階の全標本計算を今回再実行したわけではない.
