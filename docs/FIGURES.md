# Reading the saved luminosity figures

This guide describes the plots already generated by the supplied benchmark and plotting code. It adds no new plots or numerical results. Files are under [`outputs/visual/figures/`](../outputs/visual/figures/), with matching PDF and PNG versions. The numerical settings are in [`configs/visual_benchmark.json`](../configs/visual_benchmark.json), and aggregate metrics are in [`outputs/visual/summary.csv`](../outputs/visual/summary.csv).

## Quantities and conditioning

The main maps show the bin-average density of `Q_U = P_X(. | U)`, where U is the union of the declared detection regions. The analytic Gaussian truth is conditioned on the same set. This does not estimate an absolute galaxy number density. Both overflow intervals remain in the full-plane model and its normalization.

A hatch or mask marks a region in which both luminosities cannot be resolved at the deepest limit. Such a region is not filled by extrapolation from initialization. The maps do not use KDE, Gaussian display smoothing, or CDF repair. A bin-average density is not a claim about the distribution inside that bin.

## Plot families

Apart from `observed_catalogue`, every filename begins with `rho0.55` or `rho0.90` and `shallow` or `deep`. Each of the four combinations has ten plot types, giving 41 independent plots in total.

| Filename suffix | Meaning |
|---|---|
| `observed_catalogue` | Recorded detections and one-sided limits in the mock catalogue |
| `truth_Q` | Gaussian-truth bin probabilities under the same visible conditioning, converted to bin-average density |
| `naive_A` | Uncorrected A-only histogram: a deliberate information/selection ablation |
| `reconstructed_Q` | D-completion representative, normalized on U, with unresolved regions masked |
| `noD_Q` | The deliberate no-D/no-selection-denominator ablation under visible normalization |
| `residual_resolved` | Difference between the reconstructed and true maps on resolved bins |
| `bright_probability_RMSE_Q` | Error in `Q_U(X1 >= x1, X2 >= x2)` on the fixed 13x13 evaluation grid as parent sample size changes |
| `resolved_bin_L1_Q` | L1 error of resolved-bin probabilities as parent sample size changes |
| `marginal1`, `marginal2` | Conditional marginal luminosity distributions, with BOTH standardized luminosities at least -0.5 |
| `same_likelihood` | Three parent distributions with the same fitted conditional record law and different invisible mass |

The horizontal sample-size variable is the number of generated parent objects used to design the experiment; it is not passed to the estimator. Error-plot bands are empirical 10th–90th percentiles across 20 realizations, **not** 95% confidence intervals. The `same_likelihood` curves are **not** confidence bands or the complete identified set. The A-only and no-D alternatives are not correctly specified Lynden–Bell, 1/Vmax, or A-only truncated-likelihood competitors.
