# English documentation

This is the English entry point for **bivsurv-luminosity 0.1.0rc1**. The installation, public-record refit, benchmark interpretation, archived-stage explanations, and publication procedure can all be followed in English. The numerical implementation and saved scientific evidence are unchanged by this documentation edition.

The high-resolution visual fits and the archived Stage 25 certificates concern different models and candidates. Numerical stopping in the new fits is not a global-optimality proof. The record-law predictor, parent point estimate, identified range, and confidence set are also distinct objects; the English stage notes preserve those distinctions.

## Publication and manuscript status

The approved repository name is `bivsurv-luminosity`; the software licence is BSD-3-Clause. This package does not assert that a remote repository, release, or archival DOI already exists. No publication identifiers have been invented.

The scientific article is being developed in Japanese for eventual submission in English to *Astronomy and Computing*. This package provides English **software and reproducibility documentation**, not an English translation of the complete paper. Japanese manuscript fragments and original stage notes remain optional historical materials. See [manuscript scope](../manuscript/README.md).
