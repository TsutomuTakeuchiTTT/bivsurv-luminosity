# 第24段階の結果

第23段階で共通尾部クラスを外れた13設計・標本ケース(母標本としては8種類)を再解析した.
同じ16質量の観測モデル, 個数表, 初期測度R, 尾部上界を保ち, 学習予測と信頼集合は変更していない.

## 更新と停止の区別

1. 各80回, 合計1040回の制約付きGEMを実行し, 全更新で有理数の可行性・surrogate増加・観測尤度増加を確認した.
2. 二つのD所属による四群の閉形式を使い, 各M-stepの大域最大化をKKT式で確認した.
   実装は有限有理数の近似候補を採用するためGEMと呼ぶ.
3. 80回時点の最大一次方向残差の保証上界は5.68e-5〜5.33e-4であり, 収束解とは呼ばない.
4. これとは別に, 同じ制約付き観測尤度を三初期値から最大化した13個の候補を構成した.
   全候補が親クラスに入り, 80GEM後より尤度が高く, 制約付き一次残差上界は最大5.85e-14だった.
   これらをGEM更新とは呼ばず, 元の非凹尤度の大域MLEとも認定しない.

原結果の13件は非負生存分布としては正当であり, 追加尾部クラスに属さないことが問題だった.
12件は完全不可視質量を全て取り除いても制約違反が残り, 単なる全体尺度の変更では解決しない.
未制約スコアは制約境界で大きくてもよく, feasible directionsの一次残差で診断する必要がある.

参考生存RMSEは13件全てで小さくなったが, 旧クラス違反例に限定した解析であり,
一般的な統計効率・被覆の改善を示すものではない.

## 独立検証

13公開モデルを再構成し, 元の学習2EM予測の不変性を確認した.
1040更新, 16640個のM-step KKT座標等式, 13個の境界候補を再検査した.
検証器は最適化や乱数生成を呼ばず, M-step提案関数も呼ばない.
5種類の有害な改ざんを拒否した.

四群の全256有理数対照では非活性90, 第一のみ57, 第二のみ57, 両方活性52ケースを確認した.
別のSLSQP比較16件との目的差は最大6.67e-16だった.

全13ケースを別出力へ再実行し, 13証拠JSONと比較CSVが全バイト一致した.
集約JSONは時間以外が一致した.

その旧全探索を今回再実行したとは数えていない.
